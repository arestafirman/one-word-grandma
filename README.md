One word — the word grandma would text about AI — for the
[One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16)
bounty on make.fun.

`main.ts` writes the word deterministically to `/output/entry.txt`:

> ROBERT

No network, no randomness, no dependencies — the program writes one fixed
word and exits.

## Why ROBERT

Grandma heard "robot" and has been calling it Robert ever since. She texts
the machine like it is a polite young man who lives in the phone and knows
everything. Caps on, because her caps lock has been on since 2019 and nobody
has had the heart to tell her.

Checked against the judge's five criteria, in order:

1. **One word grandma would text about AI** — yes: a mishearing/typo of
   "robot" that she would actually send.
2. **Real grandma texting voice** — warm and a little baffled; she names the
   machine like a person, the way grandmas do.
3. **Funny in one word** — the robot → Robert pun lands with no caption.
4. **Tied to AI/robots/machines** — it only makes sense as "robot" said by
   grandma; as a plain name it would never be texted about AI.
5. **Fresh, not obvious** — nobody's first pick, but instantly readable.

## Candidates considered and rejected

| Candidate | Why it lost |
|---|---|
| ROBOT | Banned obvious pick — fails criterion 5 outright. |
| AI | Banned obvious pick, 2 letters, no grandma voice at all. |
| CHATGPT | Banned obvious pick; also a brand, not a grandma word. |
| WOW / WHAT / LOL / HAHA / HELLO | Banned generics — fit any subject, fail criterion 4. |
| ROBIT | Good typo of "robot", 5 letters, but the joke is only a misspelling; loses to ROBERT on warmth (criterion 2) and humour (criterion 3). |
| ROBOOT | Typo of "robot"/"reboot" confusion; muddier than ROBIT, and the reboot reading pulls away from AI. |
| RUBOT | Typo of "robot", but reads like a mumble rather than a grandma word; weaker voice than ROBIT. |
| CHATBOT | Real word, clearly AI-tied, but not funny and not grandma-voiced — a tech term, not a text from grandma. |
| ANDROID | Clearly a robot word, but cold and technical; no warmth, no joke. |
| CYBORG | Same problem as ANDROID — technical, not something grandma texts. |
| TINMAN | Grandma-era reference and warm, but "tin man" is a film character, not AI; the AI tie is a stretch. |
| CHATTY | Warm, but fits any talkative person — fails criterion 4. |
| SMARTY | Warm, but fits any clever person — fails criterion 4. |
| KNOWITALL | Funny and grandma-ish, but 9 letters and fits any know-it-all human — weaker AI tie than ROBERT. |
| BEEPBOOP | Robot sound, but internet-culture, not grandma voice; grandma would not text this. |
| DOOHICKEY | Peak grandma vocabulary, but fits any unnamed object — fails criterion 4. |
| COMPUTAR | Grandma typo of "computer", warm, but computer is not AI — fails criterion 4. |
| GIZMO | Gadget word, fits any gadget — fails criterion 4. |
| BEEP | Short robot sound, but thin: no warmth, no joke, no grandma voice. |

Head-to-head decider: ROBERT vs ROBIT. Both pass criterion 1. ROBERT wins
criterion 2 (warmer, more human grandma voice — she names the machine) and
criterion 3 (a punchline, not just a misspelling), which outrank ROBIT's
one-byte tie-break edge. ROBERT it is.
